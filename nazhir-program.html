Master Program Wakaf

Satu program bisa melebur beberapa aset tanah wakaf sekaligus (mis. tanah A + tanah B). Nilai program mewakili dana wakaf uang/berkesinambungan yang dikelola dan menjadi baseline SSOT untuk menu Laporan Program.
